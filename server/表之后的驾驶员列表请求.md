# 表阶段之后：客户端会发 `0x60CD`（要驾驶员列表）

> 2026-10-22。本文纠正一个我之前的错误判断，并给出下一关的确切位置。

---

## 1. 先纠正：上一轮「写堆无效」是误判

上一轮我用 `poke [下载器+0x0C] = 0` 把下载器弄没了，然后**在 ~27 分钟后才截图**，
看到「退回登录界面」，就判定"没有推进"。

**错了。** 真实时间线（`server/fake_auth.log`）：

```
13:51:49  第 65 张 develop/mechanic_overcustom.csv（卡住）
13:53:08  ← poke [下载器+0x0C] = 0
13:53:08  recv 20 bytes (累计 2912 = 2892 + 20)
          [frame 68] 明文 4 / 密文 16
          消息 操作码=60cd 载荷=2          ← 客户端立刻发了新请求
13:56:28  （后续还有一条 68 字节）
~13:58    idle 300 秒超时掐线 → 客户端才退回登录
```

**poke 是有效的**：状态机确实从 case 5 走到了 case 7，而 case 7 会发一条新请求。
我们从来没回过这条，所以它一直等；等到连接超时被掐，才退回登录。

## 2. 那条请求是什么：`0x60CD` = 要驾驶员列表

`FUN_00ad6ce0`（协议层）：

```c
*puVar5 = 0x60cd;
FUN_00a5a580(..., ")<-_proto_lounge_client::send_pilot_list_get( ");
```

⇒ **`0x60CD` = `send_pilot_list_get`**，请求体 2 字节（空参数）。

## 3. 它的回复归谁解析

调试字符串 `_proto_lounge_client::recv_pilot_list_get_r` 位于 `0xe0d848`，
被 `0xad00c1` 引用 → 函数 **`FUN_00aa2d50`**（2.5 万行，栈上一大堆 28 字节结构体）。

它在 **`CGVOProtoLounge` vtable（`0xe14d04`）的槽 21**。

## 4. 回复正好能打开第二道闸

同一张 vtable 的**槽 32 = `0xaf6170`**，函数体最后就是：

```
0xaf6170..0xaf618d  把 6 个参数压栈
0xaf618e            call 0xa4fae0 → 0x439190
```

而 `FUN_00439190` 的末尾正是：

```c
*(this+0x10619) = (param_7 != 0);
*(this+0x10615) = 1;          // ← 第二道闸
*(this+0x1061a) = 0;
FUN_00438b30(5);
```

⇒ **驾驶员列表的回复 → 槽 32 → 置 `+0x10615` → 步骤机 case 8 通过 → 离开「正在取得数据」。**

这也解释了为什么之前搜 `0xaf618e` 找不到调用者：它是**槽 32 的函数体尾部**，
Ghidra 在中间的 `ret` 处切了一个假函数，我按"独立函数"去找调用者自然找不到。
（`0xaf618e` 本身没有任何引用，但它所在的 `0xaf6170` 在 vtable 里。）

## 5. 现在唯一的未知：回复的**操作码**

请求是 `0x60CD`，但回复的操作码不等于它（已知配对：`0xF86A→0x5290`、
`0x8288→0x298E`、`0x3B8F→0x4F3F`、`0xA380→0x1146`、`0xF24B→0xA5DA`，看不出规律）。

分派是「操作码 → 槽位 → `vtbl[slot]`」，但目前没在代码里找到
`call [reg+slot*4]`、也没找到 `opcode → slot` 的表（可能被壳运行期重定位）。

### 建议的打法：用 `+0x10615` 当**运行时预言机**

我们能读那一字节。于是可以把"猜操作码"变成**可测量**的循环：

1. 客户端卡住后，poke 下载器让状态机走到 case 7（它会发 `0x60CD`）；
2. 我们按候选操作码依次发一条消息（正文字段先按大佬日志的 `count=1/ARR2/pilot/id/name` 猜）；
3. **每发一条就读一次 `[game+0x10615]`** —— 变成 1 就说明猜中了；
4. 猜中后再回头补全正文格式（用 `FUN_00aa2d50` 的字段偏移反推）。

这把无界搜索变成了**一次登录内可批量试错**，因为判据是一字节，不需要等界面反应。
