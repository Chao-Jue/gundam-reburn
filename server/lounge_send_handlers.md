# 客户端发包 opcode 总表（v5.0.0.33）

由 `66 c7 <modrm> imm16`（把操作码写进缓冲区首字）枚举 + 邻近 `send_*` 日志串命名，共 318 条。

⚠️ modrm 必须通配：`send_msma_msset_store` 用的是 `66 c7 07`（`[edi]`），
只认 `66 c7 45 00`（`[ebp+0]`）会漏掉它 —— 加通配后条目从 219 涨到 318。

`reserve` = 该函数里 `push imm; call session->vt[0x78]` 申请的缓冲区长度（含 2B 操作码；
是上限，可变长报文实际发出的可能更小）。
