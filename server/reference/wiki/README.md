# 机体与武器参考资料

来源：https://wiki.biligame.com/gundam/敢达OL机体对比工具 ，通过该站公开 MediaWiki API 抓取。

`units.json` 保存来源链接、修订编号、抓取时间、分类索引属性、机体属性、武器模板字段和旧式表格单元格。`raw/` 保留 API 原始响应缓存，可复查和断点重跑。

本次索引得到701条分类记录；比较页面链接中请求675项，解析并剔除首页后保留632个页面、5750条模板化武器、4908个旧式表格。27个页面HTTP567失败，列表在failures中。其余数量差还涉及重定向合并，不应理解为675台完整机体均已采集。

575个页面得到机体属性。手写旧式武器表尚未全部转换为统一武器字段，使用tables查看原始单元格。templates里的数值按原样保留，未将空白、公式、范围或图片标记强行变成数字。

是否金限为1/0的模板记录分别写成gold_only=true/false；缺失或其他值为null。金银图纸的开发次数规则尚未实现。

Wiki序号和页面ID不是当前客户端的机型/武器ID。client_unit_id目前为null，不能直接拿这些记录组游戏数据表；数值还存在版本和平衡调整差异。

重新抓取：`python tools/crawl_gundam_wiki.py`。仅抓前若干页可加`--max-pages N`，建议使用另一个`--out`目录以免覆盖完整缓存产物。遇到失败的单页会记录后继续，其余响应缓存复用。

[gow_develop_enhance_status.md](gow_develop_enhance_status.md) 是 2026-11-02 从日文超攻略 Wiki「開発・強化・ステータス」手工整理的开发、机体强化和武器强化参考，配套 JSON 同名。它不属于 `units.json` 抓取结果，也不能当作当前客户端强化公式。
