# 武器特效匹配（人工指派）

打开方式：双击 `tools/start_weapon_effect_match.cmd`（本机 127.0.0.1，无管理员权限，不改客户端）。
或手动：`python tools/weapon_effect_match.py --port 8769 --open`。

## 这个工具解决什么

客户端的 `settings/item/weapon_settings.csv` 在中文本里是 2 字节占位，原版每把武器的
枪口/弹体/刀刃特效指向无法直接读到；实验武器只能靠反复重启客户端试。这里把
`fx/` 下 5257 个可播放特效整理成可浏览的库，并把「选中的武器模型 + 选中的特效」
合成一张预览图，让人先在本机看效果，再决定写哪条路径。

## 界面

- 左栏：按标签筛选（枪口/刀刃/光束/爆炸/烟雾/火花/轨迹/光效/推进器/盾/UI），
  标签来自插件名关键词 + 对象结构，一个特效可以有多个标签；`其他`表示没有命中任何词表。
- 中间：卡片即「当前武器 + 该特效」的合成预览，缩略图用各特效自己最"满"的时刻采样。
- 右栏：大图、特效路径、槽位指派（muzzle/projectile/impact/blade/attached），
  时间滑块可看不同时刻。
- 顶部「导出人工指派」下载 JSON；服务端同时把它写在
  `server/reference/weapon_effect_match/weapon_effect_assignments.json`。

## 边界（重要）

- **不写服务端武器定义**，也不改客户端资源。导出的 JSON 只是人工复核记录，
  还要按既有流程转成实验行并实机验收。
- 预览是**离线近似合成**：正交投影 + 平面着色，Sprite/Particle 取代表样本，
  混合模式按 2/3=加算、1=常规处理，Trail 用挂点后方一条等宽光带近似，
  粒子发射、飞行、命中、音效都没有模拟。**不能当作渲染验收。**
- 分类只是缩小浏览范围，不是语义结论。比如 `PP_01_100_01` 是实测可用的粉红枪口闪光，
  但它的 VRA 里没有挂点名，标签仍是 `other`——按分类找不到时用路径搜索或「全部」。
- 武器没有 `s_shot*` 挂点时预览会退回包围盒前端，页面上会写出来，别把它当真实挂点。

## 数据规模（2026-11-03 本机）

- 特效：5257 个可浏览 VRA（另跳过 686 个 `fx/NN/attr/` 下的模型描述 PZ_*，它们不能单独播放），解析失败 0。
- 武器外观：2296 个 `item/**/EM_*.dxg`（另 131 个解析失败，索引里列出原因）。
- 归类分布：轨迹 1590、刀刃 828、光束 811、光效 743、烟雾 713、枪口 490、爆炸 471、火花 431、UI 334、盾 113、推进器 101、其他 556。

## 已知限制

- `EM_*.dxg` 里 131 个读不出来（`DXG属性索引无效` / 只有挂点没有网格），这些武器不在可选列表里。
  没有为了凑数放宽解析器——放宽会把错的数据画出来。
- 特效模型有 DXG 1.5（`fx/**/model/PM_*.dxg`），已按与 1.8 相同的块布局支持并加了回归测试。
- 单张预览首次约 20–150ms，之后走内存缓存（400 条）。
