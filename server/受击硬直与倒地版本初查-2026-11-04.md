- 0xA8F2 recv_weapon_hit_from_with_tumble，协议回调+1E8 -> AF51E0 -> A53CC0 -> 4A1040 -> 473690。
- 0xE332 recv_weapon_hit_from_with_stumble，回调+1EC -> AF5210 -> A53CF0 -> 4A1130 -> 4736C0。
- 0x45FC recv_weapon_hit_from_with_staggery，回调+1F0 -> AF5240 -> A53D20 -> 4A1200 -> 47A9B0。

原生4A1040/4A1130/4A1200先按实体取actor，再传方向、power、msec至不同actor入口；可用作后续最小原生验证入口。尚未读取器完整消费测试、服务端发包或实机动作验证。服务端training_target目前只发DDF7与49C6，未实现三类反应通知、受击累计或恢复状态；扣血已通过不意味着受击动作已实现。
