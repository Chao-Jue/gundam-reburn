## 附录：机师项字段偏移的**机械提取方法**（下次接着做）

反汇编 `FUN_00a956f0` 后，字段读写的**惯用法**是固定成对的：

```asm
; 读一个 u32
mov  eax, dword ptr [esi]        ; esi = &cursor
add  esi?, ...                   ; ← 实际是 add dword ptr [esi], 4
mov  dword ptr [edi + 0x20], eax ; edi = 项基址，0x20 = 字段偏移
add  dword ptr [esi], 4          ; 游标前进
```

所以 **(字段偏移, 字节数)** 可以直接从
`mov [edi + OFF]` / `lea [edi + OFF]` + 紧跟的 `add dword ptr [esi], N` 成对抓出来。
子结构用 `lea eax,[edi + 0x2c]; push eax; push esi; call 0xa5de30` 这种形式（19 字节）。

已确认的开头（可靠）：
```
+0x00 u32(4) | +0x04 char[25] | +0x20 u32(4) | +0x24 u8 | +0x25 u8 | +0x26 u8
| +0x28 u16(2) | +0x2C 子结构(19) | ...
```

**注意**：`add dword ptr [esi], N` 在反汇编输出里是**十进制**（`add dword ptr [esi], 4`），
正则要用 `(0x[0-9a-f]+|\d+)`。另外函数里有两处 25 字节的**内联**拷贝循环
（`cmp eax,0x19; jb`），它们不产生 `add [esi], N`，要单独加 25×2。
