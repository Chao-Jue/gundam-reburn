## 协议与已修复问题

16AC机体初始化发生在大厅初始化期间，不是每次点格纳库才请求。应答为2ACF begin(28B) → A832×N → FCE6 end(0B)。

2ACF：sv_time u32、slot_num u16、sort_sec/usec各u32、penalty/bonus/balance各u16、sort_type/order各u32。偏移20/24现设1/0。排序类型0会使0x5E0600不填排序向量，列表0x787BB6解引用空指针闪退；0x604830仅接受类型1..13、顺序0..1。已有原生离线回归测试，别改回全零。

A832：299B机体 + u32武器数(<=30) + 30B×武器 + u32装备套装数(<=7) + 套装；当前套装数0。解析器0xA96070/0xA964D0，映射JSON在server/hangar_*_wire_map.json。

机体wire关键偏移：uniqid0(u64)、msma_id8(u32)、昵称20(61B)、energy81、decal85、color89、deckslots90/91、cost94、mission_cost98、武器ID102/106/110、shield114、special118、强化计数190(u16)、强化值192(7*u16)、开发值206(7*u16)、msbits290(u16)、颜色位292(u32)、favorite298。

武器wire：`<IHH10HBB`，item_id、db_index、buildup_count、10项强化值、两项券次数。武器换槽请求0AA5正文14B=`<QHI>`；回应D9DB正文18B=`<iQHI>`。服务器持久化/验证已实现，但没有真实定义与UI验证。

编队F969→D6BC来自参考文档，**当前版本尚未验证或实现**。不可宣称可编辑编队，只是初始化占槽成功。

## 性能模板：本轮核心新发现

机型解析0x54EF50不直接读取全部最终数值。它存入一组模板名称，加载收尾0x54E830遍历机型调用0x54E2F0，从全局0x11699F4（CMSMABattleDetailTables）查模板，查不到就清零。

| msma_settings列(0基) | 类型 | 机型结构模板名偏移 |
|---|---|---|
| 56 | RESPAWN_TIME | 0x194 |
| 58 | WARP_TIME | 0x1B0 |
| 60 | COST | 0x1CC |
| 62 | MAX_HP | 0x1E8 |
| 64 | ENERGY | 0x204 |
| 67 | MOVE | 0x220 |
| 69 | BOOST_GAUGEMAX | 0x23C |
| 71 | BOOST_GAUGEHEAL | 0x258 |
| 73 | BOOST_SPEED | 0x274 |
| 79 | JUMP | 0x290 |

表实例创建0x9D8410→0x9D4A70；主vtable0xDF9538。**vt+8=0x9B1B30才是加载器**，调用0xB08960跳过前两行，行回调0x9AC5F0；vt+0=0x549B10枚举分类查找，vt+4=0x549940按类型分派。CSV第0列为类型文本，第1列模板名称，第2列起为参数。

标量整数解析0x55A610只读col2：MAX_HP、COST、WARP_TIME、BOOST_GAUGEMAX。BOOST_GAUGEHEAL用0x55A690（浮点，尚可再核对）；RESPAWN_TIME用0x549780读col2..12共11个整数。ENERGY用0x5497B0读两个整数；MOVE用0x5497E0读非负float；BOOST_SPEED用0x549810读混合10参数；JUMP用0x5498A0（尚未反编译）。速度不能不经单位换算直接将Wiki“1004”填float运动速度。

0x54E2F0最终写入：MAX_HP→row+0x94，MOVE→+0xA4，ENERGY→+0xA8/+0xAC，RESPAWN_TIME→+0xB0..+0xD8，WARP_TIME→+0xDC，COST→+0xE0，BOOST_GAUGEMAX由0x40C9B0封装（再核对布局），BOOST_GAUGEHEAL→+0xA0，BOOST_SPEED→+0xF4..+0x118，JUMP→+0x11C起。

**已写入但未经游戏验证的子集**：装甲3425、COST200、喷射容量1000、充能200、再出击时间11档均50（参考COST200复用，档位规则未实现）。WARP_TIME=10仅诊断占位，不是确认参考值。模板名GM_REF_加类型名。测试只验证CSV和引用，不证明收尾执行顺序、UI数值与单位正确。
