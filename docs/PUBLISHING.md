# 发布范围

首次新建私有GitHub仓库，以当前源码和文档快照为基线；根目录原先没有Git元数据，不伪造开发提交历史。

包含server和tools的源码、历史Markdown研究记录、结构化协议映射、选择后的参考JSON、模型匹配Web源码与vendor许可证，以及exports独立工具源码快照。server/fake_root的本地战区清单保留。

排除客户端和安装包、launcher、解码资源、server/img_dump等二进制/内存转储、抓包/运行日志、截图与图标图像、个人存档、Wiki raw缓存/旧备份、refs外部参考项目、.workbuddy个人记忆及本地配置。排除不删除本机文件。克隆仓库后需自行准备手册列出的私有输入，不能声称仓库本身提供完整游戏环境。

没有将整个第三方资源包上传GitHub，也没有把缺失原始数据伪装为可完整重建。私有仓库不改变第三方权利归属。变为公开仓库前另行确认资料许可与发布范围。

额外排除：server/_unlock_launcher.py，因含NUL并非可编译Python源文件；原件保持本地不变，异常在验证报告公开记录。
