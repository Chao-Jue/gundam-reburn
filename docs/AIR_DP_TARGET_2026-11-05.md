# 空中靶机与枪械 DP 实验

用户要求新增空中移动靶机并赋予枪械 DP，以验证空中清槽翻倒。
保留地面实体200，新增敌方实体201及独立HP/DP、快照缓存、资产实例号。
仅在原有GM打靶实验开关下生成，普通模式不新增实体。

## 行为与数据边界

- 实体201在固定XZ上以8秒周期上下移动，离地1500±300cm。
- 地面锚点来自当前F01显式DXG地形三角形；A对应D、B对应S。
  地图工具自动选中的另一地形版本不适用这些坐标，未采用其采样结果。
  这不是通用地形碰撞、原任务绑定或飞行AI。
- 777105/777108每次接受的命中回报扣800DP，是为本次测试明确设定的值，
  不是原版武器参数，也不按散弹颗粒重复累加。已有777101参考DP49不变。
- 阈值800短硬直、1600清槽。地面清槽跪地，空中清槽翻倒。
  冲刺格斗依旧强制翻倒。空中翻倒按980.665cm/s²下降至已采样地面，
  保持倒地1.5秒后清状态起身，不能在空中提前起身。
- 起身后留在地面，暂不自动重新升空；重新进入战场可重新测试空中流程。
  没有新增死亡/复活机制。
- 两个靶机共用递增同步帧序号，E4DB一次包含两个HP显示实体。
  当前9FFB00的绝对坐标列为有符号short乘2，故位置增量编码倍率为200cm；
  初始快照仍为100cm。离线原生测试验证第二缓存实体路由、符号、倍率和状态位。

## 验证

修复前先运行两个复现测试，分别因空中清槽返回跪地、实验枪械缺少DP而失败；
修复后同样测试通过。新增空中巡航、去重、落地前不可恢复、落地后地面规则、
后端独立命中路由及多实体同步帧测试。

- compile_build：修改Python文件py_compile通过。
- automated_tests：161项服务端、126项原生离线测试通过。
- runtime_integration：真实隔离服务及加密TCP通过，涵盖出击、双靶机、
  地面DP、空中两枪短硬直/翻倒、下落状态30、落地10、最终0及退出。
- TCP首轮因逐块OpenSSL进程开销与新增持续同步造成时序阻塞，中止两次。
  测试客户端改为整帧ECB并逐块保留原计数掩码、提前发出命中回报、添加超时；
  服务端加密实现未改。cryptography不可导入，未安装依赖，仍用现有OpenSSL。
- service_startup：组合重启命令被策略拒绝；分开检查与操作成功。
  原HTTP未监听（首次健康检查连接拒绝），启动后HTTP200，认证32字节握手通过。
  认证PID45664、HTTP PID41544；没有输出握手密钥。
- native_client_e2e：待用户完整重启并验收，不把离线原生执行称为实机完成。

建议B点出击，空中靶机约在其前方20米、离地12至18米，地面靶机仍保留。
枪械两次有效命中间隔约0.5至1秒，避免短硬直免疫期和DP自然恢复。
记录机体是否翻倒坠地、落地后起身，以及落地后再次清槽是否改为跪地。
