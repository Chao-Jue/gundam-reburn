# Z键紧急返回首轮

用户要求紧急返回速度受机体返回性能影响，并反馈按Z完全无反应。
现有服务日志已收到7B52（正文4字节IsCancel=0），但local_battle没有处理分支，
所以不能将无反应归因于键位或客户端未发请求。

## 当前客户端与资料

- A88180发送7B52，正文一个u32 IsCancel。
- FEBB读取器接受i32 result、u32 cancel、u16 entity、u32 countdown_msec，共14字节。
  当前443940负result走错误处理；成功0开始或取消，毫秒乘0.001写读条时间。
- E5FC正文u16实体，4440B0处理倒计时结束与返回选择状态。
  130A隐藏对应实体。原生报文游标测试覆盖全部截断、尾随拒绝。
- 原生A003B0重复收到自机快照更新已有实体，不重复登记；新测试验证重新出击坐标更新。
- 本地提供的日服2022-01-27各種検証存档：返回性能682对应吉姆10秒，
  500对应14秒、818对应7秒等。当前GM WARP_TIME10与该基准一致；
  现在显式作为基准秒数使用，不能把682直接当作秒或毫秒。
- 其他版本battle_spawn.py仅参考开始/取消/完成/隐藏的生命周期，线格式与负错误值
  均独立按当前客户端确认。没有复制其他版本模块、客户端资产或数据库。

## 实现范围

GM_RETURN_SECONDS供原生机体表WARP_TIME和服务端倒计时共用，基准10秒。
更换该性能时间配置同时改变表和读条，测试以3秒验证绑定，避免独立硬编码读条。
本轮只支持当前实验GM的基准性能；强化索引、部件与额外减时仍需当前原生消费者核对，
没有声称已实现所有机体的面板值换算或强化修正。

7B52支持开始、重复开始返回剩余时间（不延长）、取消；格式错误不处理，
未出击/不支持机体以负result拒绝。完成时E5FC+130A隐藏自机，暂停其攻击受理，
清除本次未完成手雷表现，重新开放现有选机/地点流程。返回后选择地点无需再等60秒，
仍保留已验收的归零通知与0.5秒阶段处理宽限。

地面/空中靶机对象和HP保留，重新出击不重复生成。当前没有自机完整伤害/死亡系统，
不能据此承诺返回保留所有自机损伤、弹药、部件与再出击惩罚已经完整实现。
客户端移动取消通过自身IsCancel请求，服务端不凭未经恢复的421B状态猜测取消。
