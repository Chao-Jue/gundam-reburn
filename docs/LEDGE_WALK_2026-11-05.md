# 小落差后的悬空行走

## 实机证据

用户报告从高处走下断崖后仍浮空行走；后补充主要在小落差时发生。
只读采样启动并确认自机实体1可读后，请用户走下断崖、松方向键3秒、跳跃一次。
用户反馈松开后仍悬空但缓慢下降，跳跃没有区别。

本地150秒采样共1500条，ground=1有1483条，ground=0有17条。
小落差后的停止区间，物理速度为0、接地保持1，世界高度约每秒下降5cm。
例如90.5秒Y69.86，95.5秒Y44.77，100.6秒Y19.69，105.6秒Y15.91落地。
较大落差则短暂ground=0、有负垂直速度并迅速落地。
重力向量仍为-9.80665，垂直倍率仍1；未再次增大重力或改目标接地同步。
原始采样与反编译只存本地`server/hook_runs/ledge_*`，不上传客户端/转储/日志。

## 原生链与修正

53FA30将模型CSV第5列解析到model+18。实验GM该列沿用初期通用占位值1。
4958A0是碰撞处理后的台阶高度补偿：model+18>0才进入补偿，
下降分支495B0C..495B87每秒消除`5 * model[18]`厘米的高度偏移。
此偏移保存在actor+2DC，前一碰撞位置高度在+2E0；下一帧物理积分前撤去偏移，
碰撞处理后又添加平滑偏移。因此身体悬在真实碰撞地面上方，物理速度仍0、接地仍1。
这与实机5cm/s吻合，不能把它误诊为整个重力系统失效。

本轮仅将实验GM模型第5列设为0，走原生无台阶平滑补偿分支。
保留原生地形碰撞、重力和大落差判定，不凭空设定原版台阶高度。
这是实验性的禁用未标定补偿，**不是已恢复原版台阶平衡参数**。
其他模型（包括基地）仍用原配置；该参数也会由相同GM模型的目标读取。
可能取舍：小台阶视觉跟随更直接，需确认上台阶/斜坡、跳跃落地没有卡住或穿地。
